# LiveAge — Android sideload install

Install LiveAge on Android without the Play Store using the APK attached to the latest [GitHub Release](https://github.com/dhruvpathak9305/liveage-install/releases).

## Steps

1. On your phone, open the APK download link (or scan the QR code from the LiveAge docs).
2. Android will warn that the app is from an **unknown source**. That’s expected for sideloads — allow the install for this APK / browser / Files app when prompted.
3. After install, open **LiveAge** once and set your birth date.
4. Widgets are **not** auto-placed. Long-press the home screen → **Widgets** → choose **LiveAge**, then place Small / Medium / Large.

## What’s in this repo

This repository is **public install-only**. It contains this README and release APK assets. It does **not** contain source code, signing keys, or secrets.
