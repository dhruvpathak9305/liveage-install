# LiveAge — Android sideload install

Install LiveAge on Android without the Play Store.

## Download

- **APK (stable URL):** https://github.com/dhruvpathak9305/liveage-install/releases/latest/download/liveage.apk
- **QR code** (same URL):

![Scan to download LiveAge APK](./install-qr.png)

## Steps

1. Open the APK link (or scan the QR).
2. Android will warn about **unknown sources** — expected for sideloads. Allow the install for this APK / browser / Files app when prompted.
3. Open **LiveAge** and set your birth date.
4. Widgets are **not** auto-placed. Long-press the home screen → **Widgets** → **LiveAge**, then place Small / Medium / Large.

## What’s in this repo

Public install-only: README, QR image, and release APK assets. No source code or signing keys.
